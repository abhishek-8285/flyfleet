# FlyFleet API Documentation

**Version:** 1.0.0  
**Base URL:** `https://api.flyfleet.in`  
**Protocol:** HTTPS only  
**Authentication:** JWT Bearer tokens, API Keys (for devices)  
**Date Format:** ISO 8601 (RFC3339)  
**Timezone:** UTC (all timestamps)  
**Rate Limiting:** 1000 req/hour (standard), 100 req/min (burst)

## 🔐 Authentication

All API requests require authentication using JWT Bearer tokens (for web/mobile users) or API Keys (for IoT devices).

### Web/Mobile Authentication
```http
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

### Device Authentication
```http
X-API-Key: device-api-key-here
```

### Detailed API Specifications
#### 1. POST `/api/v1/auth/register`

**Description:** Register a new organization with admin user  
**Authentication:** Public (no auth required)  
**Rate Limit:** 10 requests/hour per IP
// Request
{
  "email": "admin@company.com",
  "password": "SecurePass123!",
  "name": "John Doe",
  "phone": "+919876543210",
  "org_name": "ABC Logistics",
  "org_type": "fleet_owner",
  "gst_number": "27AABCU9603R1ZX"
}

// Response 201
{
  "user_id": "uuid",
  "org_id": "uuid",
  "email": "admin@company.com",
  "access_token": "eyJhbGciOiJIUzI1NiIs...",
  "refresh_token": "eyJhbGciOiJIUzI1NiIs...",
  "expires_in": 900
}
---

#### 2. POST `/api/v1/auth/login`

**Description:** Authenticate user and receive JWT tokens  
**Authentication:** Public  
**Rate Limit:** 20 requests/hour per IP
// Request
{
  "email": "admin@company.com",
  "password": "SecurePass123!",
  "device_id": "optional-device-identifier"
}

// Response 200
{
  "access_token": "eyJhbG...",
  "refresh_token": "eyJhbG...",
  "token_type": "Bearer",
  "expires_in": 900,
  "user": {
    "id": "uuid",
    "email": "admin@company.com",
    "role": "admin",
    "permissions": ["vehicles:*", "drivers:*"],
    "org_id": "uuid"
  }
}
---

#### 4. POST `/api/v1/auth/refresh`

**Description:** Refresh expired access token using refresh token  
**Authentication:** Refresh Token  
**Rate Limit:** 100 requests/hour
// Request
{
  "refresh_token": "eyJhbG..."
}

// Response 200
{
  "access_token": "eyJhbG...",
  "refresh_token": "eyJhbG...",
  "expires_in": 900
}

#### 25. POST `/api/v1/vehicles`

**Description:** Register a new vehicle in the fleet  
**Authentication:** JWT  
**Permission:** `vehicles:write`

**Validation:**
- Registration number must match Indian format: `^[A-Z]{2}[0-9]{2}[A-Z]{1,2}[0-9]{4}$`
- Chassis number must be 17 alphanumeric characters
- Year must be between 1900 and current year + 1
// Request
{
  "registration_number": "KA01AB1234",
  "chassis_number": "MAT12345678901234",
  "engine_number": "ENG123456789",
  "type": "truck",

  "model": "Ace",
  "year": 2023,
  "fuel_type": "diesel",
  "fuel_capacity_liters": 60,
  "documents": [
    {
      "type": "rc",

    {

| Code | Status | Description |
|------|--------|-------------|
