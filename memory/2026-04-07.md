### Architecture (CORRECTED — 2026-04-07)
- **Originally**: 16+ separate microservices (all in `services/_archive/` now)
- **Current actual**: 3 active services + archive graveyard

#### `services/fleet-core/` — THE REAL MONOLITH ✅
- Module: `github.com/flyfleet/fleet-core`
- Port: 8084
- 1709-line `cmd/main.go`, registers ALL routes
- **29 domains** in `internal/domains/`: admin_support, alert, alerts, analytics, auth, billing, compliance, customer, diagnostics, driver, emergency, finance, fuel, geofencing, governance, india, integrations, maintenance, monitoring, platform_compat, reports, route, settings, tracking, trip, vehicle, video
- 60+ migration files

- **This is the one that has EVERYTHING**

#### `services/auth-service/` — Standalone Auth
- Module: `github.com/flyfleet/auth-service`
- Port: 8080
- IAM, MFA, RBAC, TOTP, email
- Separate deployment

#### `services/monolith/` — ❌ DELETED (2026-04-07)
- Was a small tracking-only service (22 Go files, just GPS + geofencing + WebSocket)
- Redundant — fleet-core already has full tracking domain
- All references removed from go.work, docker-compose.yml, docs, product-spec

#### `services/_archive/` — 36 Deprecated Microservices

### Security Rules (from CLAUDE.md)
1. Never modify `_archive/` folder
2. Multi-tenancy: ALL queries MUST filter by `org_id`
3. DTO pattern: never expose DB models via API
4. Parameterized queries only — no string concat for SQL
5. File size limit: Go files < 1000 lines (refactor if exceeded)
6. Test coverage: 70% minimum, 80%+ for auth/billing

### Known Security Fixes (do NOT reintroduce)
- ✅ Mass Assignment (use DTOs)
- ✅ OS Command Injection (no shell in exec)
- ✅ Server-Side Template Injection (HTML sanitization)
- ✅ DoS Memory Exhaustion (MaxBytesReader)
- ✅ Cross-Tenant Message Injection (org ownership validation)
- ✅ Credential JSON Exposure (json:"-")
- ✅ Error Information Leaking (generic error messages)
